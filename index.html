Graduation Project • Web App

Shifa – Clinic Appointments & Nearby Pharmacies

Project Architectural Documentation & Final Delivery
1

The Challenge

Patients frequently encounter significant hurdles when trying to coordinate clinical consultations: fragmented scheduling systems, conflicting doctor timetables, lack of transparent reviews, and the tedious difficulty of discovering open nearby pharmacies carrying required medications right after appointments.

2

The Action

As Team Leader and Web Developer, I guided the team across the full project lifecycle. I engineered the relational database architecture supporting patients, doctors, appointments, schedules, reviews, and pharmacies with strict integrity constraints. I coordinated team task distribution, designed the complete architectural documentation (including Use Case diagrams, Activity workflows, and ERDs), and built core backend features using ASP.NET Core MVC, C#, ADO.NET, and modern responsive front-end interfaces.

3

The Result

Delivered a unified, high-performing clinic and pharmacy web ecosystem that successfully automated patient appointment booking and geolocation-based pharmacy search. The project earned distinction during academic presentation for its exceptional relational database normalization, comprehensive architectural documentation, and seamless team collaboration.
